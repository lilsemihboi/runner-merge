# AGENTS.md

## Project Shape

- This is a Roblox/Luau project. Versioned source is under `src/`; Wally dependencies are generated into ignored `Packages/`.
- Runtime entrypoints are `src/library/Server.server.luau` and `src/library/Client.client.luau`. Services are explicitly required and initialized there; adding `src/services/<name>/Server.luau` or `Client.luau` does not wire it into runtime automatically.
- `src/library/` is intentionally excluded from the source-tree generator and is mapped explicitly as the server and client roots.
- `.luaurc` enables strict Luau by default; the two library entrypoints explicitly opt into `--!nonstrict`.

## Commands

- Install JavaScript tooling with `npm install`.
- Install Wally dependencies and regenerate package types with `npm run wally-install`. This also creates ignored `sourcemap.json`; run it after changing `wally.toml` or on a fresh checkout.
- Regenerate the Rojo project tree with `npm run build:rojo` after adding, removing, or renaming files under `src/`.
- Use `npm run watch:rojo` for continuous development; it watches only `src/**/*` and rebuilds `default.project.json`.
- There are no repository-defined test or typecheck scripts. Use `stylua --check src` for formatting checks and `selene src` for linting.

## Generated Mapping

- `default.project.json` is generated by `scripts/genRojoTree.js` and ignored by Git; do not hand-edit it.
- The generator skips `src/library/`, maps filenames containing `Server` to `ServerScriptService`, and maps other Luau files to `ReplicatedStorage.Shared`.
- Generated instance names are not literal file paths: folders are PascalCased (`ui` becomes `UI`), and basenames `Server`, `Client`, `Utils`, and `Types` are prefixed with their parent folder. Match `require` paths to the generated tree.
- `assets/**` is Asphalt input and generates `src/modules/items/assets.luau`; that output is marked generated and should not be edited manually.

## Style

- StyLua is configured in `stylua.toml`: tabs, Windows line endings, 160-column width, double-preferred quotes, always-parenthesized calls, and sorted requires. Format with `stylua src`.
- Selene uses the Roblox standard library and allows mixed tables via `selene.toml`.
